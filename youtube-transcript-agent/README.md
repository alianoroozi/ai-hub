# YouTube Transcript Agent

A conversational agent that extracts and summarizes YouTube video transcripts using OpenAI. Users can interact with the agent via terminal to ask questions about YouTube videos.


## Features
- Extracts transcripts from YouTube videos using the YouTube Transcript API
- Formats transcript segments with readable timestamps (`[MM:SS]`)
- Interactive command-line interface powered by an LLM agent
- Demonstrates tool-augmented LLMs using function calling
